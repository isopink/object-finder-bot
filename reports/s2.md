## Conventions chosen (not fixed by the brief)

- Optical frame x right, y down, z forward; `depth_m` is z-depth along the
  optical axis (RealSense aligned depth), so `P_c = d * K^-1 [u, v, 1]`.
- Mount rotation: `R_base<-cam = Rz(cam_yaw) * Ry(cam_pitch) * R_body<-optical`;
  positive `cam_pitch` tilts down, positive `cam_yaw` turns left. Height is
  dropped after the transform to the map.
- Box center is `((l + r) / 2, (t + b) / 2)`.
- Depth mode noise: `r` is the 3-D camera-to-object distance; the covariance
  axes follow the horizontal ray from the camera to the object.
- nodepth bearing: measured from the robot position (`view_pose`), to match
  `ray_gaussian(pose, ...)` and the memory's EKF, which uses `view_pose` as the
  ray origin. The camera ray starts at the camera, a few cm away, so the bearing
  is taken to the ray's point at `nominal_range` from the camera. With the
  default mount (5 cm ahead) the error at other ranges is below 0.015 rad, half
  of `sigma_bearing`. With pitch it uses the full pixel ray (column and row).
- `in_view` uses the horizontal distance from the camera position and the
  camera heading `pose.yaw + cam_yaw`; occlusion is not modeled.
- `median_depth`: the central `frac` of both width and height, clipped to the
  image, at least one pixel; values that are 0, negative, or NaN are ignored.
- `triangulate` returns None when the rays are within 3 degrees of parallel or
  the intersection is behind either pose.
- Unknown `camera_mode` raises `ValueError` in `observe`.

## Contract changes

- None required.
- Optional, for later: an `Observation.origin` (camera xy) would let the EKF use
  the true ray origin instead of `view_pose`; the error it removes is below
  half of `sigma_bearing`, so it is not needed for the demo.
