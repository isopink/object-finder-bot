# 원고 → 슬라이드 기호 (UOS 표준)

같은 폴더의 `DESIGN.md`와 함께 쓴다. Seminar_8_05의 `handoff/template.md`에 있던 규칙을 그대로 옮겼다.

## 구조 기호
- 머리말 `cover-image` / `cover-caption` = 표지 오른쪽 프로젝트 대표 이미지와 캡션 (v3.0, 학교 엠블럼 대신)
- `---` = 슬라이드 구분
- `# Part N : 제목` = Part 표지. 다음 줄 `*부제*`는 이탤릭 부제
- `##` = 슬라이드 제목 (좌상단, 검정 #1a1a1a)
- `###` = 제목 밑 요약 한 줄 (연한 회색)
- `**굵게**` = 굵게, 검정 (v3.0부터 색 없음)
- `==강조==` = 강조색 마룬, 장당 1~2곳만 (v3.0, DESIGN.md 10장)
- `|||` = 좌우 2단 (박스 없이 컬럼, 가운데 얇은 세로선). "묶어서 표시"라고 적으면 톤 박스
- 컬럼 첫 줄 `**..**` = 컬럼 제목 (검정)
- `>>` = 하단 가운데 결론 문구 (검정 짧은 바 + 500 굵기 문구, 박스 없음)
- `(그림: ~)` = 도식 요청 → SVG로 직접 그림
- `![[파일명.png]]` = 이미지 삽입 (assets/에 실제 파일 필요)
- `[[사진 n]]` = 아직 안 채운 사진 자리. 바로 밑 `(...)`는 배치·크기·출처 지침. 파일이 오기 전까지 점선 상자로 렌더
- `[[영상 n]]` = 아직 안 채운 영상 자리. `[[사진 n]]`과 같은 점선 상자로 렌더
- `[ ___ ]` = 나중에 채울 숫자·값 (회색 굵은 글씨로 그대로 표시)
- `>` = 발표자 노트 (슬라이드에 안 나옴)
- `$$...$$` = 독립 수식 (KaTeX, PPTX에는 이미지)
- `$$...$$ (n)` = 번호 붙은 수식 (v2.0). 번호는 덱 전체에서 이어 붙임
- `§ 3.2 Method` (장 첫 줄) = 섹션 표시, 제목 위에 작게 (v2.0)
- `Fig. n. 설명` = 그림 캡션, 그림 아래 (v2.0)
- `Table n. 설명` + 마크다운 표 = 3선 표, 캡션은 표 위 (v2.0)
- `(a) 제목` / `(b) 제목` / `(c) 제목` = 그림 패널. 사례 장은 Symptom → Diagnosis → Fix (v2.0)
- `[n]` = 본문 속 인용, References 번호와 같음 (v2.0)

## 논문 리뷰 형식 (v2.0)
- 순서와 그림·표·수식 규칙은 `DESIGN.md` 9장. 한 장의 중심은 그림 하나, 글은 캡션과 결론 한 줄이 맡는다.

## 레이아웃 방침
- 본문이 세로로 꽉 차게 (본문 영역 flex 세로 중앙)
- 2단에서 좌우 컬럼 제목 높이를 맞춤
- 이미지가 세로로 여러 장이면 object-fit: contain으로 높이 제한 (넘침 방지)
- 문구는 되도록 한 줄
- 같은 도식이 연속된 장에 나오면 크기·위치 동일

## 내용 방침
- 수식은 결과 수식 1개 + 한 줄 해석. 유도와 상세는 Appendix
- 비유를 수식보다 먼저
- 오타는 자연스럽게 고침

## 템플릿 묶음 (zip)
- `DESIGN.md`, `Rules.md`, `build/export.py`, `vendor/` 를 고치면 `python build/pack_template.py` 로 `out/uos_design_template.zip` 을 다시 만들어 바탕화면 사본을 바꾼다.
- zip 안 `README.md` 에 버전(`DESIGN.md` 의 version)과 만든 날이 찍힌다.

## 동반 문서 (원고와 항상 함께 고침)
- `발표 노트.md`: 장별 핵심 메시지 (개조식, Q&A용)
- `발표 대본.md`: 장별 구어체 대본 + 전환 멘트
- `사진 소싱 가이드.md`: `[[사진 n]]` 자리별 소싱처·배치·저작권
- 장을 추가하거나 지우면 세 문서의 번호도 다시 매김
