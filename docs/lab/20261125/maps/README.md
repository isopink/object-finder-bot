## 정리
- 지도가 안 꺾인 원인은 SLAM이 아니라 **odom의 회전**이었다. 지도를 그리기 전에 제자리 90°로 `/odom`을 먼저 본다.
- 데모에 쓸 만한 지도는 **4번 `room_l`** 하나 (벽 겹침 주의). 다음 실습에서 `OFB_ODOM_IMU=0`으로 다시 그리는 것을 추천.
