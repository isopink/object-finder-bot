트러블슈팅 18~22번에 자세한 내용이 있다. 여기는 한눈에 보는 요약.

| 우회: 바퀴 기준 회전 (`OFB_ODOM_IMU=0`) | 🟡 | 제자리 90° 한 번 확인 (+91.6°). 다음 세션에서 재확인 필요 |

| Jetson 갑자기 꺼짐 | ❌ | 오후에도 3번 이상. 전원 선 고정 필요 (13번) |

## 다음 실습 순서 (제안)
1. Jetson 전원 선 고정 → 켜고 **시계 동기화 확인** (`timedatectl`, 19번)
2. OpenCR 리셋 (USB 뽑기 → 스위치 OFF/ON → 도레미 → USB)
3. `OFB_ODOM_IMU=0 ./robot/bringup.sh` → 제자리 90° 돌려서 `/odom`이 따라가는지 확인
4. `./robot/slam.sh` + `python3 robot/lib/live_map.py` → 브라우저로 보면서 ㄱ자 운전
5. 꺾임이 지도에 보이면 `./robot/save_map.sh room_l`

## 같이 본 것
- 카메라(C920)가 로봇의 **뒤쪽**에 달려 있음: `w`를 누르면 카메라 반대쪽으로 간다. `nodepth.yaml`의 `cam_x 0.205`(앞쪽 기준)와 맞지 않는다. 카메라를 `w` 방향으로 옮기거나 값을 고쳐야 한다.
- 확인용 `ros2` 명령을 자주 쓰면 통신이 꼬인다 (20번). 확인은 로그 파일로.
