## 3. 실행 방법 (지금 구성)

Jetson:
```bash
cd ~/object-finder-bot && git pull
export OFB_DDS_WIDE=1 OFB_ODOM_IMU=0 OFB_DETECTOR=owl OFB_OWL_PROMPTS="a cup,a laptop" OFB_TILES=0
./robot/start_all.sh room_l4_nav depth
```
